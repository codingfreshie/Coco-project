
# CS F363: Compiler Construction Project

Compiler Construction project for the CS F363 course at BITS Pilani, Pilani Campus.

---

## 📂 Repository Structure

* **`driver.c`**: Main driver file that handles execution flow and testing.
* **`grammar.txt`**: Language grammar specifications and production rules.
* **`custom_t*.txt`**: Custom test cases (`custom_t1.txt` to `custom_t6.txt`) used for verifying parser and compiler correctness.
* **`Makefile`**: Build automation script for compiling and cleaning the workspace.
* **`LICENSE`**: GPL-3.0 open-source license.
